# What's changed

This page lists the changes to the guide to assembling a dataset of New York City Council discretionary funding that a reader would notice: new sections, new data, data fixes, and corrections when we published something wrong. Newest first.

- **History begins:** 2026-10-08. The guide was first published on this date. Corrections made before it may be missing.
- **Data refresh:** Not on a schedule. The guide reads files saved in this repository, and its downloads run only when someone turns them on by hand.

To report a bug in this guide, or to ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/schedule-c-assembly-guide/issues).

## 2026-11-12: New page listing what has changed in this guide

- **Tags:** Site
- **What changed:** This page is new. It lists the changes to the guide that a reader would notice. If we ever publish a number that turns out to be wrong, this page will say so plainly. A link to it will appear in the footer of every page the next time the guide is rebuilt.
- **More detail:** [The change history in this repository](https://github.com/BetaNYC/schedule-c-assembly-guide/commits/main)

## 2026-10-08: The guide is published

- **Tags:** Site, Data
- **What changed:** The first version of the guide went online. It reads the Council's yearly Excel files of discretionary awards for fiscal years 2009 to 2026 into one table, renames their columns to match NYC Open Data, and compares them with the City Council Discretionary Funding dataset on NYC Open Data for the years both cover.
- **More detail:** [The guide](https://betanyc.github.io/schedule-c-assembly-guide/) · [The change](https://github.com/BetaNYC/schedule-c-assembly-guide/commit/bfc9a71949f21c5f677b7a88a35a96ac1421405f)
